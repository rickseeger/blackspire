# Black Spire — audio sources & licenses

Every sound in `assets/audio/` is a **real downloaded recording**, not a
synthesized beep. All files were downloaded from Wikimedia Commons, a
CC0 / public-domain / CC-BY archive, and were then trimmed, resampled to
22.05 kHz mono 16-bit WAV, and peak-normalized with ffmpeg (ambient beds to
-8 dB, action sounds to -1.5 dB, so the action layer is clearly louder).

## Attribution

CC BY 4.0 files (the Gravity Sound game-audio pack and the Work With Sounds
